## Overview

CoFoundr AI is a single-page React application that gives founders on-demand access to an executive team they could not otherwise afford. Instead of unstructured brainstorming, it routes each business idea through a purpose-built advisory workflow:

- **Small local businesses** (chai stalls, cafés, bakeries, salons, kirana stores) get a practical **Shop Execution Plan** focused on footfall, lean equipment budgets, and daily profit economics — no venture pitch required.
- **Tech startups** (SaaS, AI platforms, FinTech, DeepTech) get a **Tri-Agent Boardroom** where CTO, CMO, and CFO personas debate architecture, go-to-market, and investor narrative.

The app also includes a slide-by-slide pitch-deck audit studio, a hybrid human + AI advisory marketplace, and transparent pricing tiers.

> **Status:** Front-end prototype. AI responses are generated by a deterministic mock engine that runs entirely in the browser — no backend or API key required. See [Demo Mode & API Keys](#demo-mode--api-keys).

## Features

### 🧠 Adaptive Concept Classifier
A keyword-and-regex classifier (`src/utils/businessClassifier.ts`) reads the founder's idea and automatically selects the right advisory track. Tech-intent keywords (`SaaS`, `AI`, `platform`, `API`, `LLM`, etc.) override local-retail keywords, so "AI for coffee shops" is correctly treated as a tech startup.

### 💬 Co-Founder Hub
A chat workspace with specialized advisory personas:

| Agent | Role | Focus |
|---|---|---|
| **Dr. Evelyn Vance** | Technical Co-Founder (CTO) | Architecture, latency, vector search, SOC-2, model cascades |
| **Marcus Sterling** | Growth & GTM Co-Founder (CMO) | ICP, pricing elasticity, CAC payback, sales velocity |
| **Elena Rostova** | Fundraising Co-Founder (CFO/IR) | Seed multiples, dilution, investor narrative, cap table |
| **Retail & Shop Advisor** | Micro-Retail Specialist | Location footfall, equipment budgets, unit economics, launch checklist |

Capabilities include simulated token streaming, business-type detection, structured plan cards, copy/export of executive memos, and quick-start playbooks.

### 📊 Pitch Diagnostics Studio
A slide-by-slide critique of a pitch deck with per-slide scores, strengths, vulnerabilities, and the exact questions investors are likely to ask. Includes sample deck data and export actions.

### 🏛️ Advisory Board Marketplace
A searchable roster of vetted human advisors and AI persona directors across AI/DeepTech, SaaS, FinTech, and HealthTech, with credentials, availability, rates, ratings, and booking flows.

### 💳 Pricing
Three transparent tiers with monthly/annual billing toggle:

| Plan | Price | Audience |
|---|---|---|
| **Bootstrap** | Free | Early-stage founders validating an idea |
| **Venture** | $49/mo ($39 annual) | Pre-seed & seed teams actively raising |
| **Enterprise Studio** | $199/mo ($159 annual) | Venture studios, accelerators, Series A cohorts |

### 🎨 Polished Marketing Surface
Custom animated aircraft/neural-brain SVG hero, bento capability grid, founder case studies, brand monogram watermark, and a fully responsive dark interface.

## How It Works

```text
Founder enters an idea
        │
        ▼
┌──────────────────────────┐
│  detectBusinessType()    │  keyword + regex classification
└────────────┬─────────────┘
             │
     ┌───────┴────────┐
     ▼                ▼
 Small shop       Tech startup
     │                │
     ▼                ▼
 Shop Plan        Tri-Agent Boardroom
 (footfall,       (CTO · CMO · CFO
  equipment,       consensus on tech,
  unit economics)  GTM, fundraising)
     │                │
     └───────┬────────┘
             ▼
   Structured advisory memo
   (cards, reasoning trace, export)
```

Navigation is state-driven (`overview`, `hub`, `advisory`, `diagnostics`, `pricing`) — there is no router and no persistence layer, so a page refresh resets the session.

## Getting Started

### Prerequisites

- **Node.js 20.19+** (or 22.12+) — required by Vite 8
- **npm** (bundled with Node.js)

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/0syedamaryam0-web/cofoundr-ai.git
cd cofoundr-ai

# 2. Install dependencies
npm install

# 3. Start the dev server
npm run dev
```

Open **http://localhost:3000** in your browser.

> The Vite dev server is configured for port `3000` and `host: 0.0.0.0` (accessible on your LAN).

### Production build

```bash
npm run build     # outputs static assets to dist/
npm run preview   # serves the production build locally
```

## Demo Mode & API Keys

This build is **fully self-contained**:

- All advisory responses, pitch diagnostics, and plan data are generated locally in `src/components/AIChatHub.tsx` using `setTimeout`-driven mock streaming.
- **No network requests** are made and **no Gemini API key is required** to explore every screen.
- `.env.example` documents `GEMINI_API_KEY` and `APP_URL` for future server-side integration; `@google/genai` is installed but not yet wired up.

To switch to live Gemini responses later, add a server-side endpoint (never expose the key in client code), set `GEMINI_API_KEY`, and replace the mock branch in `AIChatHub.tsx`.

> **Never commit real secrets.** `.gitignore` excludes `.env*` and re-includes `.env.example`.
